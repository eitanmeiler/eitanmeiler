### Hi, I'm Eitan

I work at the intersection of film and data: I study what makes movies open big, and I build tools that make breaking into the industry less chaotic.

**Projects**

- 🎬 **[Opening Night](https://github.com/eitanmeiler/Prediction-Model)**: a forward-tested model of US opening-weekend box office for 1,959 wide releases (2010–2025). Hypotheses are written down before modeling, 2025 is a sealed holdout, and live forecasts are frozen in git before each release.
- 🟢 **[Greenlight](https://github.com/eitanmeiler/greenlight)**: an internship tracker for film, media and policy students. A daily crawler pulls postings from public job boards; the app rates fit, tracks applications, and checks tailored resumes for honesty.

**Tools I use:** Python (pandas, scikit-learn, CatBoost) · JavaScript · SQL · Cloudflare / Vercel / Supabase
